## New modules

| Feature | Realm | Subfolder | Name | Job (one line) |
|---|---|---|---|---|
| Locker | shared | Data | LockerTypes | Locker, Outcome, Odds, OpenResult, the saved LockerState |
| Locker | shared | Data | LockerConstants | the two Lockers (currency, key price, rarity odds), pity factor, refunds, direct prices, slice name |
| Locker | shared | Rules | LockerRules | pool, real odds, pity guarantee, the roll, refunds, direct price, what the screen shows |
| Locker | shared | Rules | LockerRequestRules | build/parse the open and direct-buy requests |
| Locker | shared | Net | LockerEvents | OpenRequest, BuyRequest, Result, Status (restricted) |
| Locker | server | (root) | LockerServiceServer | the `lockers` account slice, open and direct-buy transactions, the restricted check |
| Policy | server | (root) | PolicyServiceServer | per-player PolicyService info, cached, fail-closed `paidRandomItemsRestricted` |
| Locker | client | (root) | LockerServiceClient | sends requests, plays the opening scene on a result, keeps the restricted flag |
| Locker | client | State | LockerStore | the restricted flag, the last result, the opening in progress |
| UI | client | Screens/Locker | LockerViewModel | the Shop Lockers tab and odds sheet values (specced) |
| UI | client | Screens/Locker | LockerPanel | the Shop Lockers tab (two Locker cards, what's inside, restricted list) |
| UI | client | Screens/Locker | LockerOddsSheet | the odds sheet |
| UI | client | Screens/Locker | LockerOpeningScreen | stage-1 opening (shake, key, flash, rays) before the reveal |

Changed: CosmeticTypes `GrantSource` gains "locker"; PlayerDataTypes/PlayerDataConstants gain the `lockers` account
field; StateSync registry + client store gain `lockers`; ShopViewModel's Lockers tab is no longer "soon"; ShopScreen
renders LockerPanel on that tab.
